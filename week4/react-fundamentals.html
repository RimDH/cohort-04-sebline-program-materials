22 / JSX

What is JSX?

JSX is a syntax extension for JavaScript that lets us describe UI with HTML-like markup inside JavaScript.

const name = "Sara";

function Greeting() {
  return (
    <section>
      <h2>Hello {name}!</h2>

    </section>

}
23 / JSX

Important JSX rules

01Return one parent element—or use a Fragment <>...</>.
02Close every tag: <img />, <input />.
03Use className instead of HTML class.
04Most DOM properties use camelCase, such as onClick.
05Use curly braces to insert JavaScript expressions.

27 / PROPS

Props are read-only.

A child receives data

The child should not modify the props it receives.

  • Parent owns the value
  • Child receives the value
  • If data needs to change, use state in the appropriate component
function UserCard({ name }) {
  // Do not do this:
  // name = "New Name";

  return <h3>{name}</h3>;
}

32 / STATE

Do not change state directly

WRONG

function handleClick() {
  count = count + 1;
}

// React is not told to re-render.
CORRECT

function handleClick() {
  setCount(count + 1);
}
34 / STATE

Do not mutate objects or arrays in state

OBJECT
const [user, setUser] = useState({
  name: "Sara",
  age: 20
});

setUser({
  ...user,
  age: 21
});
ARRAY
const [skills, setSkills] =
  useState(["HTML", "CSS"]);

setSkills([
  ...skills,
  "React"

41 / RENDERING

Why does React need a key?

Keys identify list items

React uses keys to understand which items were added, removed or reordered.

  • Use a stable unique ID from your data
  • The key must be unique among siblings
  • Avoid array indexes when list order can change

47 / USEEFFECT

The dependency array matters

1No arrayEffect runs after every render
2[]Effect sets up after the component is added
3[value]Effect runs again when that dependency changes
useEffect(() => {
  document.title = `Count: ${count}`;
}, [count]);
48 / USEEFFECT

Some Effects need cleanup.

useEffect(() => {
  const timer = setInterval(() => {
    console.log("Running...");
  }, 1000);

  return () => {
    clearInterval(timer);
  };
}, []);
WHY CLEANUP? Stop timers, subscriptions or other external work when the component no longer needs them.
49 / USEEFFECT

"Why did my Effect run twice?"

DEV

React Strict Mode can do this in development

React may run an extra setup + cleanup cycle for Effects in development to help reveal bugs.

This does not mean production runs every Effect twice.

Do not remove Strict Mode just to hide the issue. Write Effects that clean up correctly.

50 / API CONSUMPTION

Fetch API data in a component

import { useEffect, useState } from "react";

function Users() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    async function loadUsers() {
      const response = await fetch(
        "https://jsonplaceholder.typicode.com/users"
      );

      const data = await response.json();
      setUsers(data);
    }

    loadUsers();
  }, []);

  return <p>Users: {users.length}</p>;
}
51 / API CONSUMPTION
function Users() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    async function loadUsers() {
      try {
        const response = await fetch(
          "https://jsonplaceholder.typicode.com/users"
        );

        if (!response.ok) {
          throw new Error("Could not load users");
        }

        const data = await response.json();
        setUsers(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    }

    loadUsers();
  }, []);

  if (loading) return <p>Loading...</p>;
  if (error) return <p>{error}</p>;

  return users.map(user => (
    <p key={user.id}>{user.name}</p>
  ));
}
