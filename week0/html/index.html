01 / THE WEB'S STRUCTURE

HTML gives content meaning.

HTML (HyperText Markup Language) is the markup that describes what each part of a page is.

Structure

Headings, paragraphs, sections, navigation, and page landmarks.

Content

Text, images, links, lists, tables, forms, and media.

Meaning

Semantic elements tell browsers and assistive technology how content is organized.

03 / START WITH A VALID DOCUMENT

The page skeleton.

Every document has a frame

The doctype selects modern HTML. The head stores metadata (information about the webpage); the body holds visible page content.

  • Set the language
  • Declare UTF-8
  • Set the viewport
  • Give the page a title
<!DOCTYPE html>
<html lang="en">
	<head>
		<meta charset="UTF-8">
		<meta name="viewport"
			content="width=device-width, initial-scale=1">
		<title>My page</title>
	</head>
	<body>
		<h1>Hello, web</h1>
	</body>
</html>
04 / TEXT ELEMENTS

Build a clear reading order.

Use headings by hierarchy

A page normally has one main heading, followed by nested section headings. Pick a heading for meaning, not its visual size.

  • <p> for a paragraph
  • <strong> for importance
<h1>Student profile</h1>
<p>I build useful web experiences.</p>

<h2>What I am learning</h2>
<p>Currently focused on <strong>HTML and CSS</strong>.</p>

<h2>A note</h2>
05 / CONNECT DOCUMENTS

Links connect the web.

/

Relative link

<a href="about.html">About</a>
Move to a page in your project.

https

External link

<a href="https://example.com">Visit</a>
Connect to another website.

#

Same-page link

<a href="#contact">Contact</a>
Jump to an element with that ID.

06 / IMAGES THAT INCLUDE EVERYONE

Images need context.

Write useful alternative text

Describe the information an image contributes. For a decorative image, use an empty alt value.

  • Use a real project path
  • Keep alt text concise
  • Caption complex images
<img src="images/profile.jpg"
		 alt="Alex smiling at a laptop"
		 width="320" height="240">

<figure>

			 alt="Sales rise steadily from May to August">

		Monthly sales, May to August
	</figcaption>
</figure>

08 / SEMANTIC HTML

Choose elements by purpose.

Semantic landmarks make the page easier to navigate, maintain, and understand.

PAGE INTRO<header>Logo and page heading
PRIMARY LINKS<nav>Site or section navigation
MAIN CONTENT<main>Unique page content
RELATED / END<aside> <footer>Supporting content and ending
ALSO USE <section> for a themed group; <article> for self-contained content.
09 / PUT THE LANDMARKS TOGETHER

A page with meaningful regions.

Prefer purpose over generic wrappers

Use a <div> when no semantic element fits. Don't choose an element just because of its default appearance.

<header>
	<a href="/">My portfolio</a>
	<nav aria-label="Main navigation">
		<a href="/projects.html">Projects</a>
		<a href="/contact.html">Contact</a>
	</nav>
</header>
<main>
	<article>
		<h1>About me</h1>
		<p>I make things for the web.</p>
	</article>
</main>
<footer>Made with care</footer>
10 / ELEMENT DETAILS

Attributes add information.

01href: destination for a link, such as href="/contact.html".
02src: file location for an image, video, or script.
03alt: text alternative for an image.
04class: reusable name for styling or scripting.
05id: unique identifier for one element in a document.
11 / TABULAR DATA

Use tables for relationships.

Rows and columns have meaning

Tables are for data that belongs in a grid, not for arranging the whole page.

  • <caption> names the table
  • <th> labels a row or column
  • <td> holds a value
<table>
	<caption>Workshop schedule</caption>
	<thead>
		<tr>
			<th scope="col">Day</th>
			<th scope="col">Topic</th>
		</tr>
	</thead>
	<tbody>
		<tr>
			<th scope="row">Monday</th>
			<td>HTML structure</td>
		</tr>
	</tbody>
</table>
16 / ACCESSIBILITY FROM THE START

Make the page work for more people.

01Use semantic landmarks and a logical heading order.
02Give informative images useful alt text; use alt="" for decoration.
03Give form controls visible, associated labels.
04Use link text that says where the link goes, not just "click here".
05Keep keyboard focus visible and provide captions for video.
17 / DEBUG THE MARKUP

Small checks prevent broken pages.

CHECK THE STRUCTURE

Common problems

  • Missing closing tags
  • Elements nested in invalid places
  • More than one page-level <h1>
  • Missing alt text or form labels
  • Reusing the same ID
CHECK THE RESULT

Useful habits

  • Indent nested elements
  • Use descriptive names
  • Validate the document
  • Inspect the page in a browser

HTML FOUNDATIONS / EXTRA EXAMPLE 02

Understand the tags.

Most elements have opening and closing tags.

  • Attributes belong in the opening tag
  • Some elements such as img, br and hr are void elements
  • Use proper nesting
<p class="intro">Hello, students!</p>

<!-- opening tag: <p class="intro"> -->
<!-- content: Hello, students! -->
<!-- closing tag: </p> -->

<img src="photo.jpg" alt="A student">
HTML FOUNDATIONS / EXTRA EXAMPLE 03

From file to browser.

The browser interprets HTML markup.

  • The head provides document information
  • The body contains page content
  • HTML5 uses <!DOCTYPE html>
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Page</title>
</head>
<body>
  Hello World
</body>

HTML FOUNDATIONS / EXTRA EXAMPLE 04

Six heading levels.

Choose heading levels by structure, not appearance.

  • h1 is the highest heading level
  • Avoid skipping levels unnecessarily
  • Paragraphs use <p>
<h1>Website title</h1>
<h2>About us</h2>
<h3>Our team</h3>
<h4>Developers</h4>
<h5>Frontend</h5>
<h6>React</h6>
HTML FOUNDATIONS / EXTRA EXAMPLE 05

Breaks and separators.

Two useful void elements.

  • <br> makes a line break within content
  • <hr> marks a thematic break
  • Do not use repeated br tags for spacing
<p>Beirut, Lebanon<br>Digital Hub</p>

<h2>Our services</h2>
<hr>
<p>Web development training</p>
HTML FOUNDATIONS / EXTRA EXAMPLE 06

Give words meaning.

HTML has elements for emphasis and quotations.

  • strong indicates importance; em indicates stress emphasis
  • blockquote is for longer quotations
  • Use semantic meaning, not only visual appearance
<p><strong>Important:</strong> Save your work.</p>
<p><em>Practice</em> every day.</p>
<p><b>Bold appearance</b> and <i>alternate voice</i>.</p>
<blockquote>Learning happens by building.</blockquote>
<p>She said <q>Keep trying!</q></p>
HTML FOUNDATIONS / EXTRA EXAMPLE 07

Nest elements correctly.

Close inner elements before outer elements.

  • Indent nested elements for readability
  • Close tags in reverse opening order
  • Use a validator to catch mistakes
<!-- Correct -->
<p>Learn <strong>HTML</strong> today.</p>

<!-- Incorrect -->
<p>Learn <strong>HTML</p></strong>

<!-- Correct nested list -->
<ul>
  <li>Frontend
    <ul><li>HTML</li><li>CSS</li></ul>
  </li>
</ul>
HTML FOUNDATIONS / EXTRA EXAMPLE 08

Control list numbering.

Ordered lists are for sequences.

  • start changes the first number
  • reversed counts downward
  • Use ul when order does not matter
<ol start="3">
  <li>Write HTML</li>
  <li>Open the browser</li>
</ol>

<ol reversed>
  <li>Third place</li>
  <li>Second place</li>
  <li>First place</li>
</ol>
HTML FOUNDATIONS / EXTRA EXAMPLE 09

Terms and definitions.

Pair a term with its explanation.

  • dl is the list
  • dt is the term
  • dd is its description
<dl>
  <dt>HTML</dt>
  <dd>Defines web page structure.</dd>
  <dt>CSS</dt>
  <dd>Controls presentation.</dd>
  <dt>JavaScript</dt>
  <dd>Adds behavior.</dd>
</dl>
HTML FOUNDATIONS / EXTRA EXAMPLE 10

Display special characters.

Use character references when needed.

  • &lt; represents < and &gt; represents >
  • &amp; represents &
  • &nbsp; is a nonbreaking space; avoid using it for layout
<p>Copyright &copy; 2026</p>
<p>Use &lt;p&gt; for paragraphs.</p>
<p>Tom &amp; Jerry</p>
<p>One&nbsp;word-like&nbsp;group</p>
HTML FOUNDATIONS / EXTRA EXAMPLE 11

Generic containers.

Use these when no more meaningful element fits.

  • div is a generic block container
  • span is a generic inline container
  • Semantic HTML is usually clearer
<div>
  <h2>Student profile</h2>
  <p>Hello, <span>Alex</span>!</p>
</div>

<!-- Prefer semantic elements where possible -->
<section>
  <h2>Projects</h2>
  <p>My recent work</p>
</section>
HTML FOUNDATIONS / EXTRA EXAMPLE 12

Navigate with paths.

Paths are relative to the current HTML file.

  • ./ means the current directory
  • ../ means the parent directory
  • Check filenames and capitalization
<a href="about.html">Same folder</a>
<a href="pages/contact.html">Subfolder</a>
<a href="../index.html">Parent folder</a>
<a href="./about.html">Current folder</a>
<a href="https://example.com">Full URL</a>
HTML FOUNDATIONS / EXTRA EXAMPLE 13

More useful links.

Open external pages and email apps.

  • target="_blank" opens a new tab or window
  • mailto: opens the configured email handler
  • A fragment link targets an element id
<a href="https://example.com"
   target="_blank" rel="noopener noreferrer">
  Visit example
</a>

<a href="mailto:hello@example.com">
  Email us
</a>

HTML FOUNDATIONS / EXTRA EXAMPLE 14

Rows and columns.

Use tables for structured data.

  • tr creates a table row
  • th creates a header cell
  • td creates a data cell
<table>
  <caption>Student scores</caption>
  <tr><th>Name</th><th>Score</th></tr>
  <tr><td>Alex</td><td>90</td></tr>
  <tr><td>Sam</td><td>85</td></tr>
</table>
HTML FOUNDATIONS / EXTRA EXAMPLE 15

Structure a data table.

Organize headers, body and footer.

  • thead groups column headings
  • tbody groups table data
  • tfoot groups summary rows
<table>
 <thead>
  <tr><th scope="col">Item</th><th scope="col">Qty</th></tr>
 </thead>
 <tbody>
  <tr><td>Books</td><td>3</td></tr>
  <tr><td>Pens</td><td>2</td></tr>
 </tbody>
 <tfoot>
  <tr><th scope="row">Total</th><td>5</td></tr>
 </tfoot>
</table>
HTML FOUNDATIONS / EXTRA EXAMPLE 16

Merge table cells.

Use colspan and rowspan when data spans cells.

  • colspan merges columns
  • rowspan merges rows
  • Keep header relationships understandable
<table>
 <tr><th colspan="2">Workshop</th></tr>
 <tr><th>Day</th><th>Topic</th></tr>
 <tr><td rowspan="2">Monday</td><td>HTML</td></tr>
 <tr><td>Lists</td></tr>
</table>
HTML FOUNDATIONS / EXTRA EXAMPLE 17

Display an image.

The src and alt attributes are essential.

  • src is the image file location
  • alt describes meaningful image content
  • Width and height help reserve space
<img src="images/student.jpg"
     alt="Student working at a laptop"
     width="360" height="240">

<!-- Decorative image -->
<img src="images/decoration.png" alt="">
HTML FOUNDATIONS / EXTRA EXAMPLE 18

Make images links.

Wrap an image in an anchor.

  • The image becomes clickable
  • A thumbnail can link to a full-size image
  • Use descriptive alt text for linked images
<a href="profile.html">
  <img src="images/student-small.jpg"
       alt="View Alex’s profile" width="180">
</a>

<a href="images/student-large.jpg">

</a>

Add image captions.

A figure groups content with its caption.
