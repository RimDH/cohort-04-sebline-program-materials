01 / DOM FUNDAMENTALS

What is the DOM?

DOM stands for Document Object Model. The browser turns your HTML into JavaScript-accessible objects.

HTMLYour source code<h1>, <p>, <button>...
→
BROWSERParses the pageBuilds an internal representation
→
DOMJavaScript can use itRead, change, create and remove elements
02 / DOM FUNDAMENTALS

The DOM is a tree.

Elements become nodes

  • document represents the current webpage
  • HTML elements have parent/child relationships
  • JavaScript can navigate and manipulate these nodes
<body>
  <main>
    <h1>Hello</h1>
    <button>Click</button>
  </main>
</body>

document
└─ body
   └─ main
      ├─ h1
      └─ button
03 / SELECTING ELEMENTS

First: find the element.

BY ID
<h1 id="title">Hello</h1>

const title =
  document.getElementById("title");

Useful when the element has a unique ID.

CSS SELECTOR
const title =
  document.querySelector("#title");

const card =
  document.querySelector(".card");

querySelector() returns the first matching element.

04 / SELECTING ELEMENTS

Select multiple elements

querySelectorAll()

Returns a NodeList containing all matching elements.

  • Use CSS selectors
  • Loop through the results with forEach()
  • NodeList indexes start at 0
const buttons =
  document.querySelectorAll(".btn");

buttons.forEach(function (button) {
  console.log(button.textContent);
});
05 / CHANGING CONTENT

Change what the user sees.

TEXTCONTENT
const message =
  document.querySelector("#message");

message.textContent =
  "Welcome to JavaScript!";

Best for plain text.

INNERHTML
message.innerHTML =
  "<strong>Welcome!</strong>";
06 / CHANGING APPEARANCE

JavaScript can change styles.

Direct style changes

The style property changes inline styles.

  • Good for small dynamic values
  • CSS property names use camelCase in JavaScript
  • For reusable styling, prefer classes
const box = document.querySelector(".box");

box.style.backgroundColor = "blue";
box.style.color = "white";
box.style.padding = "20px";
07 / CHANGING APPEARANCE

Prefer classList for real UI changes

Let CSS handle the design

  • add() adds a class
  • remove() removes a class
  • toggle() switches a class on/off
  • contains() checks whether a class exists
.hidden {
  display: none;
}

const panel = document.querySelector(".panel");

panel.classList.add("hidden");
panel.classList.remove("hidden");
panel.classList.toggle("hidden");

09 / CREATING ELEMENTS

Create new HTML with JavaScript.

Create → configure → insert

  • createElement() creates the element
  • Set its text, classes or attributes
  • append() adds it to the page
const list = document.querySelector("#list");

const item = document.createElement("li");
item.textContent = "JavaScript";
item.classList.add("skill");

list.append(item);
10 / CREATING ELEMENTS

Elements can also be removed.

remove()

Once you have selected an element, removing it is simple.

const notification =
  document.querySelector(".notification");

notification.remove();
11 / EVENTS

What is an event?

An event is something that happens in the browser that JavaScript can respond to.

CLICK

Mouse

click, dblclick, mouseenter and more.

KEY

Keyboard

keydown and keyup.

FORM

Form & input

submit, input, change, focus and blur.

12 / EVENTS

Listen for an event

1SelectFind the element
→
2ListenChoose an event
→
3RespondRun a function
const button = document.querySelector("#btn");

button.addEventListener("click", function () {
  console.log("Button clicked!");
});
13 / EVENTS

The function runs later.

Event callback

The browser waits. When the event happens, it calls your function.

  • The function is not executed immediately
  • It is passed to addEventListener()
  • One element can listen for different events
function showMessage() {
  console.log("Clicked!");
}

button.addEventListener(
  "click",
  showMessage
);
15 / FORMS & INPUTS

Read what the user typed.

Use the value property

Inputs keep their current value in JavaScript.

<input id="nameInput" type="text">

const input =
  document.querySelector("#nameInput");

console.log(input.value);
16 / FORMS & INPUTS

React while the user types.

The input event

Runs whenever the value changes through user input.

const input = document.querySelector("#nameInput");
const preview = document.querySelector("#preview");

input.addEventListener("input", function () {
  preview.textContent = input.value;
});
17 / FORMS & INPUTS

Handle a form submission.

Listen on the form

Forms submit by default, which usually reloads or navigates the page.

  • Use the submit event
  • Use preventDefault() when handling it in JavaScript
const form = document.querySelector("#signupForm");

form.addEventListener("submit", function (event) {
  event.preventDefault();

  console.log("Form handled with JavaScript");
});
18 / FORMS & INPUTS

Simple client-side validation.

Check before continuing

Client-side checks improve the user experience, but the server must still validate important data.

form.addEventListener("submit", function (event) {
  event.preventDefault();

  const name = input.value.trim();

  if (name === "") {
    message.textContent = "Name is required";
    return;
  }

  message.textContent = `Welcome ${name}!`;
});
