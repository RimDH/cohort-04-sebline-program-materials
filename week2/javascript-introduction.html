06 / WHERE JAVASCRIPT RUNS

Client-side vs server-side

CLIENT-SIDE

Runs in the user's browser

  • Requires a browser environment
  • The downloaded code executes on the user's device
  • Examples: button clicks, menus, form feedback, page updates
SERVER-SIDE

Runs on a server

  • The server processes the code and sends back a result
  • The user does not see the internal server process
  • Examples: database queries, authentication, payments, APIs
07 / WHERE JAVASCRIPT RUNS

JavaScript started browser-first.

Its early mainstream role was client-side scripting in browsers. Today JavaScript also runs on servers and many other environments.

BROWSER

Client-side JS

Chrome, Firefox, Safari and Edge execute JavaScript for webpages.

NODE

Server-side JS

Node.js runs JavaScript outside the browser and is widely used for APIs and backend services.

MORE

Beyond websites

JavaScript is also used for mobile apps, desktop apps, tooling and automation.

21 / CONDITIONS & LOGIC

Programs need to make decisions.

if → else if → else

JavaScript checks conditions from top to bottom.

  • If a condition is true, its block runs
  • If not, JavaScript checks the next condition
  • else is the fallback
const grade = 75;

if (grade >= 90) {
  console.log("Excellent");
} else if (grade >= 70) {
  console.log("Good");
} else if (grade >= 50) {
  console.log("Passed");
} else {
  console.log("Failed");
}
22 / CONDITIONS & LOGIC

Compare values carefully

LOOSE EQUALITY — ==

May convert types first

5 == "5"   // true
0 == false // true

JavaScript may perform type coercion before comparing.

STRICT EQUALITY — ===

Value + type must match

5 === "5"   // false
5 === 5     // true
false === 0 // false

Recommended: use === and !== most of the time.

25 / CONDITIONS & LOGIC

Another way to choose:
switch

Useful for exact choices

Use switch when one value can match several specific cases.

  • case defines a possible match
  • break stops the switch after a match
  • default is the fallback
const day = "Monday";

switch (day) {
  case "Monday":
    console.log("Start of the week");
    break;
  case "Friday":
    console.log("Almost weekend");
    break;
  default:
    console.log("Regular day");
}

28 / LOOPS & REPETITION

Keep a running total

The accumulator pattern

Create a variable before the loop, then update it during each repetition.

  • Start total at 0
  • Add the current value each time
  • Print the final result after the loop
let total = 0;

for (let i = 1; i <= 10; i++) {
  total += i;
}

console.log(total); // 55
29 / LOOPS & REPETITION

A quick look at while

Repeat while a condition is true

Always make sure something changes inside the loop so it can eventually stop.

  • Initialize before the loop
  • Check the condition
  • Update inside the loop
let i = 1;

while (i <= 5) {
  console.log(i);
  i++;
}
30 / FUNCTIONS

Functions package reusable logic.

Define once, call many times

A function gives a block of logic a name.

  • Parameters are inputs the function can receive
  • Arguments are the actual values passed in
  • return sends a result back
function calculateTotal(price, quantity) {
  return price * quantity;
}

const total = calculateTotal(10, 3);
console.log(total); // 30

34 / OBJECTS

Objects group related data.

Key → value thinking

An object lets us keep related information together under one variable.

  • Properties have names called keys
  • Each key stores a value
  • Use dot notation to read a property
const student = {
  name: "Sara",
  age: 20,
  course: "Full-Stack",
  active: true
};

console.log(student.name); // Sara
console.log(student.age);  // 20

54 / CHALLENGING EXERCISE 09

Student grade report

09

Object + function + condition

Create a student object with name, grade1, grade2 and grade3. Then create a function that receives the object, calculates the average and returns Excellent for 90+, Good for 70+, Passed for 50+, otherwise Failed.

55 / CHALLENGING SOLUTION 09

Solution · Student grade report

const student = {
  name: "Sara",
  grade1: 80,
  grade2: 75,
  grade3: 70
};

function gradeReport(student) {
  const average = (student.grade1 + student.grade2 + student.grade3) / 3;

  if (average >= 90) return "Excellent";
  if (average >= 70) return "Good";
  if (average >= 50) return "Passed";
  return "Failed";
}

console.log(`${student.name}: ${gradeReport(student)}`); // Sara: Good
