Live Student Search

Challenge: Search for students by name and update the visible list as the user types.

  "Sara Ahmad", "Omar Khaled",
  "Lina Hassan", "Ali Nasser", "Maya Saleh"
];
const input = document.querySelector("#searchInput");
const list = document.querySelector("#studentList");

function displayStudents(names) {
  list.innerHTML = names
    .map(name => `<p>${name}</p>`)
    .join("") || "No students found";
}

displayStudents(students);

input.addEventListener("input", () => {
  const text = input.value.toLowerCase();
  const matches = students.filter(name =>
    name.toLowerCase().includes(text)
  );
  displayStudents(matches);
});
  1. Show all students when the page first loads.
  2. Listen for the input event.
  3. Convert the search text to lowercase.
  4. filter() keeps names that include the text.
  5. Call the same rendering function with the matches.
  6. The original array remains unchanged.
Exercise 4 · Medium

Grade Statistics Dashboard

reduce()filter()Spreadsort()

Challenge: Calculate the number of students, average grade, passing students, and highest grade.

Try the live demo

Grades: 85, 45, 90, 75, 95

Starter HTML

<button id="calculateBtn">Calculate</button>
<div id="statistics"></div>
const grades = [85, 45, 90, 75, 95];
const button = document.querySelector("#calculateBtn");
const output = document.querySelector("#statistics");

button.addEventListener("click", () => {
  const total = grades.length;
  const sum = grades.reduce((acc, grade) =>
    acc + grade, 0);
  const average = total ? sum / total : 0;
  const passed = grades.filter(grade => grade >= 60);
  const sorted = [...grades].sort((a, b) => b - a);
  const highest = sorted[0] ?? "N/A";

  output.innerHTML = `
    <p>Students: ${total}</p>
    <p>Average: ${average}</p>
    <p>Passed: ${passed.length}</p>
    <p>Highest: ${highest}</p>`;
});
  1. length counts the grades.
  2. reduce() adds all grades: 390.
  3. Divide by 5 to get an average of 78.
  4. filter() finds the four grades ≥ 60.
  5. Copy the array using spread before sort().
  6. Read the first sorted value: 95.

Dynamic Task Manager

Object shorthandSpreadmap()filter()

Challenge: Add tasks, mark them complete, and delete them without modifying the original array in place.

Try the live demo

0 tasks completed

No tasks yet.

Starter HTML

<input id="taskInput" placeholder="Task">
<button id="addBtn">Add Task</button>
<div id="taskList"></div>
let tasks = [];
const input = document.querySelector("#taskInput");
const list = document.querySelector("#taskList");

document.querySelector("#addBtn")
  .addEventListener("click", () => {
    const title = input.value.trim();
    if (!title) return;
    const newTask = {
      id: crypto.randomUUID(),
      title, // Object shorthand
      completed: false
    };
    tasks = [...tasks, newTask];
    input.value = "";
    render();
  });

function completeTask(id) {
  tasks = tasks.map(task => task.id === id
    ? { ...task, completed: !task.completed }
    : task);
  render();
}

function deleteTask(id) {
  tasks = tasks.filter(task => task.id !== id);
  render();
}

function render() {
  list.replaceChildren();
  tasks.forEach(({ id, title, completed }) => {
    const row = document.createElement("div");
    const name = document.createElement("span");
    name.textContent = title;
    if (completed) name.style.textDecoration = "line-through";
    const done = document.createElement("button");
    done.textContent = "Toggle";
    done.addEventListener("click", () => completeTask(id));
    const remove = document.createElement("button");
    remove.textContent = "Delete";
    remove.addEventListener("click", () => deleteTask(id));
    row.append(name, done, remove);
    list.append(row);
  });
}
render();
  1. Start with an empty tasks array.
  2. Read and validate the input.
  3. Create a new task with a unique ID and shorthand title.
  4. Use spread to append a task in a new array.
  5. map() creates a new array with the selected task updated.
  6. filter() removes the selected task.
  7. Rebuild the visible list after every change.
Exercise 6 · Medium

Persistent Notes — Local Storage

localStorageJSON.stringify()JSON.parse()Spread

Challenge: Start with no notes. Add a note, then refresh the browser: your notes should still be there. No backend or JSON file is needed.

Try the live demo

Tip: Save a note and refresh this HTML page. Notes are stored in this browser for this page's origin.

Starter HTML

<input id="noteInput" placeholder="Write a note">
<button id="saveNote">Save Note</button>
<div id="noteList"></div>
const KEY = "workshopNotes";
const input = document.querySelector("#noteInput");
const list = document.querySelector("#noteList");

// Read saved strings and turn them back into an array.
function loadNotes() {
  try {
    const saved = localStorage.getItem(KEY);
    const result = JSON.parse(saved ?? "[]");
    return Array.isArray(result) ? result : [];
  } catch (error) {
    return []; // Handle invalid saved data.
  }
}

let notes = loadNotes();

function displayNotes() {
  list.replaceChildren();
  if (notes.length === 0) {
    list.textContent = "No notes yet.";
    return;
  }
  notes.forEach(note => {
    const item = document.createElement("p");
    item.textContent = note; // Safe for user input.
    list.append(item);
  });
}

document.querySelector("#saveNote").addEventListener("click", () => {
  const note = input.value.trim();
  if (!note) return;
  notes = [...notes, note];
  try {
    localStorage.setItem(KEY, JSON.stringify(notes));
    input.value = "";
    displayNotes();
  } catch (error) {
    notes = loadNotes();
    alert("Could not save your note.");
  }
});

displayNotes();
  1. Start with an empty list if there is no saved data.
  2. getItem() reads the saved string (or null).
  3. ?? "[]" provides a valid empty-array string when nothing is saved.
  4. JSON.parse() converts the stored string back into an array. try/catch handles invalid saved data.
  5. On Save, read and trim the input, then use spread to create an updated array.
  6. JSON.stringify() converts the array to a string because Local Storage only stores strings.
  7. setItem() saves it; render the updated notes using safe textContent.
  8. Refresh to prove the saved notes persist.

Fetch Users from an API

async / awaitfetch()try / catch / finallyDestructuring

Challenge: Click Load Users to request data from a public API, show a loading message, then display five user cards. Handle failures gracefully.

Try the live demo

Click Load Users to start.

No users loaded yet.

Requires internet access. Data source: JSONPlaceholder public demo API.

Starter HTML

<button id="loadUsers">Load Users</button>
<div id="users"></div>
const button = document.querySelector("#loadUsers");
const output = document.querySelector("#users");

async function loadUsers() {
  button.disabled = true;
  output.textContent = "Loading users...";

  try {
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/users"
    );
    if (!response.ok) {
      throw new Error(`HTTP error: ${response.status}`);
    }

    const users = await response.json();
    output.replaceChildren();

    users.slice(0, 5).forEach(({ name, email }) => {
      const card = document.createElement("div");
      const heading = document.createElement("h3");
      const info = document.createElement("p");
      heading.textContent = name;
      info.textContent = email;
      card.append(heading, info);
      output.append(card);
    });
  } catch (error) {
    output.textContent = "Could not load users. Try again.";
    console.error(error);
  } finally {
    button.disabled = false;
  }
}

button.addEventListener("click", loadUsers);
  1. Use async function because loading data takes time.
  2. Disable the button and display a loading message.
  3. await fetch(url) waits for the HTTP response without blocking the page.
  4. Check response.ok: HTTP errors do not automatically make fetch() throw.
  5. await response.json() reads and parses the API's JSON response into JavaScript values.
  6. Use slice(0, 5) and destructuring to display five names and emails.
  7. catch displays a friendly error for network or parsing failures.
  8. finally re-enables the button whether the request succeeds or fails.

Exercise 9 · Beginner-friendly

Multi-Number Calculator

Rest parameters ...Default parametersimport / export

Challenge: Enter numbers separated by commas, choose an operation, and calculate. The solution also shows how to split the calculation into two JavaScript modules.

Try the live demo

Choose an operation.

Starter HTML

<!-- index.html -->
<input id="numbers" placeholder="10, 20, 30">
<button id="sumBtn">Sum</button>
<div id="result"></div>
<script type="module" src="app.js"></script>
// math.js
export function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}
export function average(numbers, fallback = 0) {
  if (numbers.length === 0) return fallback;
  return sum(...numbers) / numbers.length;
}

// app.js
import { sum, average } from "./math.js";
const input = document.querySelector("#numbers");
const result = document.querySelector("#result");

document.querySelector("#sumBtn").addEventListener("click", () => {
  const parts = input.value.split(",").map(s => s.trim());
  const numbers = parts.map(Number);
  if (parts.some(s => s === "") ||
      numbers.some(n => !Number.isFinite(n))) {
    result.textContent = "Enter valid numbers separated by commas.";
    return;
  }
  result.textContent = `Sum: ${sum(...numbers)}`;
});
// Try displaying average(numbers) with another button.
  1. In math.js, export makes functions available to other files.
  2. ...numbers in the function parameter is a rest parameter: it collects arguments into an array.
  3. reduce() adds all numbers.
  4. fallback = 0 is a default parameter used when no fallback argument is passed.
  5. In app.js, import reuses the exported functions.
  6. split(",") creates strings; map(Number) converts them to numbers after validation.
  7. sum(...numbers) spreads an array into separate arguments.
  8. Run modules using Live Server, not by opening the HTML with file://.

Independent Counters

ClosuresLexical scopeArrow functions

Challenge: Create two counters. Each counter remembers its own value. Increment or reset one without affecting the other.

Try the live demo

Counter A0
Counter B0

Starter HTML — Two Counters

<h3>Counter A: <span id="countA">0</span></h3>
<button id="incrementA">+1 A</button>
<button id="resetA">Reset A</button>

<h3>Counter B: <span id="countB">0</span></h3>
<button id="incrementB">+1 B</button>
<button id="resetB">Reset B</button>
function createCounter() {
  let count = 0;

  return {
    increment: () => ++count,
    reset: () => { count = 0; return count; }
  };
}

// Create TWO independent counters
const counterA = createCounter();
const counterB = createCounter();

// Counter A: connect both buttons
const countA = document.querySelector("#countA");
document.querySelector("#incrementA").addEventListener("click", () => {
  countA.textContent = counterA.increment();
});
document.querySelector("#resetA").addEventListener("click", () => {
  countA.textContent = counterA.reset();
});

// Counter B: connect both buttons
const countB = document.querySelector("#countB");
document.querySelector("#incrementB").addEventListener("click", () => {
  countB.textContent = counterB.increment();
});
document.querySelector("#resetB").addEventListener("click", () => {
  countB.textContent = counterB.reset();
});
  1. createCounter() defines a private local variable count.
  2. It returns two functions that can still access that variable after createCounter() finishes.
  3. This remembered access is called a closure.
  4. increment() increases the private value and returns it.
  5. reset() changes it back to zero.
  6. counterA and counterB each get a separate private count variable.
  7. The A buttons call only counterA; the B buttons call only counterB.
