What is Git vs. GitHub?

A Distributed Version Control System that tracks changes in your local files. It works offline.

◆ GitHub (The Cloud)

A cloud platform to host Git repositories. It enables collaboration, Code Review.

Remote

Key Terms

Repository: Your project folder. Commit: A saved snapshot. Branch: A parallel version of code.

02 / GIT & GITHUB

01. Installation & Verification

Before coding, ensure Git is installed on your machine.

  1. Create Account: Sign up at github.com
  2. Download Git: Visit git-scm.com

Verify Installation

git --version

If you see a version number (e.g., 2.x.x), you are ready to go.

03 / GIT & GITHUB

02. Global Git Configuration

Set your identity so your commits are attributed to you.

git config --global user.name "Your Full Name"
git config --global user.email "YourEmail@test.com"
git config --global init.defaultBranch main
git config --global core.editor "code --wait"

The last command ensures VS Code is your default editor for commit messages.

04 / GIT & GITHUB

03. SSH + Secure Connection

Instead of typing your password every time, use SSH Keys for secure, automated authentication.

  1. Open Git Bash and generate key: 
    ssh-keygen -t ed25519 -C "Youremail@test.com"
  2. Start the agent and copy the key: 
    eval "$(ssh-agent -s)"
cat ~/.ssh/id_ed25519.pub
05 / GIT & GITHUB

Connecting to GitHub

1. Copy the output from the previous slide starting with ssh-ed25519...

2. Go to GitHub: Settings -> SSH and GPG keys -> New SSH key.

Test Connection

ssh -T git@github.com

If successful, you'll see: "Hi [User]! You've successfully authenticated..."

06 / GIT & GITHUB

04. Cloning & Initializing

Option A: Clone an existing repo

git clone git@github.com:USERNAME/proj_name.git

Option B: Initialize in an existing local folder

git init
git add .
git commit -m "Initial commit"
git remote add origin SSH_LINK_OF_YOUR_REPO
git push origin main

08 / GIT & GITHUB

06. Feature Branching

Never work directly on main. Create a branch for new features.

git branch my-new-branch      # Create
git checkout my-new-branch    # Switch to it
# ... make changes ...
git push -u origin my-new-branch

Note: -u sets the "upstream" so you can just type git push next time.

09 / GIT & GITHUB

07. Merging Local Updates

After your feature is done, bring those changes into main.

git checkout main         # Go to main
git pull origin main      # Get latest updates from others
git merge origin/my-new-branch
git push origin main

Repeat this for every branch to keep the project synchronized.

10 / GIT & GITHUB

Syncing the Team

After a merge, every developer needs to update their local branch.

git pull origin main

What is "Fetch"?

git fetch origin downloads the latest history from GitHub but **does not touch your files**. It's safe to run anytime to "look" at what others have done.

13 / GIT & GITHUB

Essential Git & GitHub Terms (1)

KEY VOCABULARY
  • Repository (Repo): A project folder tracked by Git that contains your code and history.
  • Commit: A saved snapshot of your project's changes at a specific point in time.
  • Branch: An independent version of your code used to develop features without affecting the main project.
MORE TERMS
  • Main Branch: The primary branch that usually contains the stable version of the project.
  • Clone: Creating a copy of a remote repository on your local machine.
  • Remote Repository: A repository hosted online, such as on GitHub.
14 / GIT & GITHUB

Essential Git & GitHub Terms (2)

KEY VOCABULARY
  • Push: Uploading your local commits to a remote repository.
  • Pull: Downloading and integrating changes from a remote repository.
MORE TERMS
  • Merge: Combining changes from one branch into another.
  • Pull Request (PR): A request to review and merge changes from one branch into another on GitHub.
  • Conflict: A situation where Git cannot automatically merge changes because the same code was modified differently.
15 / GIT & GITHUB

Essential Git & GitHub Terms (3)

KEY VOCABULARY
  • Staging Area: A temporary area where changes are prepared before being committed.
  • git add: A command used to move changes into the staging area.
  • git commit: A command used to save staged changes to the repository history.
MORE TERMS
  • git status: A command that shows the current state of your working directory and staged files.
  • git log: A command that displays the commit history of a repository.
  • git stash: A command that temporarily saves uncommitted changes so you can work on something else.
16 / GIT & GITHUB

Essential Git & GitHub Terms (4)

KEY VOCABULARY
  • .gitignore: A file that tells Git which files and folders should not be tracked.
  • README: A file that explains the project, setup instructions, and usage information.
  • Fork: Creating your own copy of someone else's GitHub repository.
MORE TERMS
  • Issue: A GitHub feature used to track bugs, tasks, or feature requests.
  • Release: A published version of a project, often associated with a specific milestone.
  • Open Source: Software whose source code is publicly available for anyone to view and contribute to.
17 / GIT & GITHUB

Pro Features to Know

  • Pull Requests (PR): Asking teammates to review code before merging on GitHub.
  • .gitignore: A file that tells Git which files (like passwords) to ignore.
  • README: A file that provides information about the project, including its purpose, setup instructions, and usage guidelines.
