02 / BOOTSTRAP FUNDAMENTALS

Start with a CDN

Add Bootstrap to HTML

Put the CSS link in <head>. The JS bundle is needed for interactive components like dropdowns and modals.

Keep your own stylesheet after Bootstrap to customize it.

<!-- In <head> -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Before </body> -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

05 / BOOTSTRAP FUNDAMENTALS

Spacing without writing CSS

Read the utility name

m = margin, p = padding; t = top, b = bottom, x = left/right, y = top/bottom.

For example, mt-3 means margin-top at spacing step 3.

p-3 (padding)
mt-3 (margin-top)
<div class="p-3 bg-primary text-white">Box</div>
<div class="mt-3 px-4 py-2 bg-light">Another box</div>

08 / BOOTSTRAP FUNDAMENTALS

Containers control width

.container has responsive maximum widths. .container-fluid stays full-width.

.container-fluid — full width
.container — centered, limited width

<div class="container-fluid">Full-width content</div>

10 / BOOTSTRAP FUNDAMENTALS

Know the breakpoints

Bootstrap 5 uses min-width breakpoints. A class remains active at that width and above until another rule overrides it.

PrefixViewport widthTypical reference
None (xs)Below 576pxSmall phones
sm≥ 576pxLarge phones
md≥ 768pxTablets
lg≥ 992pxLaptops
xl≥ 1200pxDesktops
xxl≥ 1400pxLarge screens
11 / BOOTSTRAP FUNDAMENTALS

One class per breakpoint

Read this combination

col-12: full width by default.

col-md-6: half width from 768px.

col-lg-4: one-third width from 992px.

With three cards: 1 → 2 → 3 columns.

<div class="row g-3">
  <div class="col-12 col-md-6 col-lg-4">Card 1</div>
  <div class="col-12 col-md-6 col-lg-4">Card 2</div>
  <div class="col-12 col-md-6 col-lg-4">Card 3</div>
</div>

13 / BOOTSTRAP FUNDAMENTALS

Display utilities change by width

Show or hide elements

d-none hides by default.

d-md-block displays from 768px and up.

d-flex flex-column flex-md-row stacks items on mobile and places them in a row on tablets and wider.

<div class="d-none d-md-block">
  Visible on md and larger
</div>

<div class="d-flex flex-column flex-md-row gap-3">
  <div>First</div>
  <div>Second</div>
</div>
