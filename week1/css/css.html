01 / CSS LEARNING PATH

What is CSS?

CSS stands for Cascading Style Sheets. It controls how HTML content looks.

HTML

Structure

Headings, text, images and links.

CSS

Appearance

Colors, fonts, spacing and layout.

JS

Behavior

Interactions and dynamic changes.

02 / CSS LEARNING PATH

Your first CSS rule

Selector → property → value

A rule selects HTML elements and declares how to style them.

  • h1 selects all first-level headings
  • color is the property
  • blue is the value
h1 {
  color: blue;
  font-size: 32px;
}

/* CSS comments look like this */
03 / CSS LEARNING PATH

Three ways to add CSS

INLINE
<h1 style="color: blue;">Hello</h1>
INTERNAL
<style>
  h1 { color: blue; }
</style>
04 / CSS LEARNING PATH

External CSS

Separate content from styling

Use an external stylesheet for real projects.

  • One CSS file can style many pages
  • Changes are easier to maintain
  • Link the stylesheet in <head>
<!-- index.html -->
<link rel="stylesheet" href="style.css">
<h1>Welcome</h1>

/* style.css */
h1 { color: #1677c8; }
05 / CSS LEARNING PATH

CSS selectors

Choose what to style

Selectors identify which elements receive declarations.

  • Element: p
  • Class: .card
  • ID: #hero (unique in the document)
p { color: #444; }
.card { padding: 20px; }
#hero { background: #eef8ff; }

<p class="card" id="hero">Hi!</p>
06 / CSS LEARNING PATH

Reusable classes

Write once, reuse everywhere

Classes prevent repeating the same inline styles.

  • Use descriptive class names
  • One element can have multiple classes
  • Prefer classes for routine styling
<button class="btn primary">Save</button>
<button class="btn">Cancel</button>

.btn { padding: 12px 20px; }
.primary { background: #1677c8; color: white; }
07 / CSS LEARNING PATH

Combining selectors

Target elements precisely

Use descendants, groups and pseudo-classes.

  • .card p targets paragraphs inside cards
  • h1, h2 groups selectors
  • :hover matches pointer hover
h1, h2 { font-family: Arial; }
.card p { color: #555; }
.btn:hover { opacity: 0.85; }
08 / CSS LEARNING PATH

Colors and backgrounds

Start with a small, consistent color palette.

color

Text color

Sets the foreground color of text.

background

Background

Sets a background color or image.

09 / CSS LEARNING PATH

Fonts and text

Make content readable

Typography creates hierarchy and improves reading.

  • font-family selects the typeface
  • font-size controls size
  • line-height improves paragraph readability
body {
  font-family: Arial, sans-serif;
  color: #25313b;
}
h1 { font-size: 36px; }
p { font-size: 16px; line-height: 1.6; }
10 / CSS LEARNING PATH

Margin vs padding

Outside vs inside

Both create space, but in different places.

  • Padding is inside the border
  • Margin is outside the border
  • Use spacing consistently
 .card {
  padding: 20px;
  margin: 16px;
  border: 1px solid #ddd;
}
11 / CSS LEARNING PATH

The box model

Every element occupies a box

Element dimensions include content, padding and borders.

  • content → padding → border → margin
  • box-sizing: border-box simplifies sizing
  • Avoid fixed heights for text-heavy content
* { box-sizing: border-box; }
.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #ccc;
}
12 / CSS LEARNING PATH

Sizing and units

Choose flexible measurements

Relative sizes help designs adapt.

  • px for precise borders or details
  • rem (Root EM) & em for scalable text and spacing
  • % for flexible containers
.container {
  width: 90%;
  max-width: 1000px;
   
}
p { font-size: 1rem; }

14 / CSS LEARNING PATH

Display basics

How elements participate in layout

Block and inline elements behave differently by default.

  • block starts on a new line
  • inline flows with text
  • inline-block accepts dimensions while remaining inline
div { display: block; }
span { display: inline; }
.badge { display: inline-block; padding: 6px; }
15 / CSS LEARNING PATH

Introducing Flexbox

Layout along one axis

Flexbox arranges children in a row or column.

  • Set display: flex on the parent
  • Children become flex items
  • The main axis depends on flex-direction
.row {
  display: flex;
  gap: 16px;
}
<div class="row">
  <div>One</div><div>Two</div>
</div>
16 / CSS LEARNING PATH

Flex direction

Row or column?

Choose the direction that matches the content.

  • row places items horizontally
  • column stacks items vertically
  • gap creates space between flex items
.navigation {
  display: flex;
  flex-direction: row;
  gap: 20px;
}
.mobile-list { flex-direction: column; }
17 / CSS LEARNING PATH

Flex alignment

Control available space

Understand main-axis and cross-axis alignment.

  • justify-content controls the main axis
  • align-items controls the cross axis
  • center is not always the best choice
.toolbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}
18 / CSS LEARNING PATH

Flex wrapping

Allow items to move to new lines

Avoid horizontal overflow when items do not fit.

  • flex-wrap: wrap permits multiple lines
  • flex: 1 1 220px allows flexible cards
  • Avoid forcing fixed widths on small screens
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
.card { flex: 1 1 220px; }
19 / CSS LEARNING PATH

What is the cascade?

When multiple declarations affect the same property, CSS decides which one applies.

01

Importance & origin

Normal and important declarations follow cascade priority.

02

Specificity

Selectors differ in how specifically they target an element.

03

Source order

If competing declarations tie, the later one wins.

20 / CSS LEARNING PATH

Cascade in action

HTML
<p class="notice">Hello!</p>
CSS
p { color: blue; }
.notice { color: red; }

/* Text is red: class is more specific. */
21 / CSS LEARNING PATH

Specificity

Which selector wins?

Compare selector specificity within the same cascade priority.

  • ID selectors outrank classes
  • Classes outrank type selectors
  • Avoid unnecessary !important
p { color: blue; }
.note { color: green; }
#warning { color: red; }

<p id="warning" class="note">Alert</p>
/* Result: red */

Responsive design

A responsive page adapts to the available screen width.

PHONE

Small screens

Readable text, stacked content and comfortable tap targets.

TABLET

Medium screens

More room for cards and navigation.

DESKTOP

Large screens

Wider layouts without excessively long text lines.

23 / CSS LEARNING PATH

Mobile-first CSS

Start with the smallest layout

Write base styles for phones, then enhance for larger screens.

  • Use flexible widths
  • Keep content readable without zooming
  • Add min-width media queries as needed
.cards {
  display: flex;
  flex-direction: column;
  gap: 16px;
}
@media (min-width: 768px) {
  .cards { flex-direction: row; }
}
24 / CSS LEARNING PATH

Media queries

Apply styles conditionally

Media queries respond to viewport conditions.

  • Choose breakpoints based on content
  • Test widths between common devices
  • Do not depend on device model names
h1 { font-size: 2rem; }

@media (min-width: 768px) {
  h1 { font-size: 3.5rem; }
}
25 / CSS LEARNING PATH

Responsive Flexbox

Stack on phones, align on desktops

Flex direction can change at a breakpoint.

  • Start with flex-direction: column
  • Switch to row when space allows
  • Allow wrapping when needed
.hero {
  display: flex;
  flex-direction: column;
  gap: 24px;
}
@media (min-width: 800px) {
  .hero { flex-direction: row; }
}

Include Bootstrap CSS

Use a versioned official Bootstrap CDN link in your HTML.

  • The browser loads prebuilt component styles
  • Your custom stylesheet can come afterward
  • Interactive Bootstrap components need its JS bundle
<!-- Example: link to Bootstrap 5 CSS -->
<link rel="stylesheet"
 href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">

<link rel="stylesheet" href="style.css">

Bootstrap forms

Use consistent form controls

Semantic HTML still matters when using Bootstrap.

  • form-control styles inputs

       type="text" required>

30 / CSS LEARNING PATH

What is SCSS?

SCSS is a Sass syntax that compiles into standard CSS.

$

Variables

Reuse design values like colors.

&

Nesting

Keep related selectors together.

@

Mixins

Reuse groups of CSS declarations.

31 / CSS LEARNING PATH

SCSS variables

SCSS
$brand: #1677c8;
.button {
  background: $brand;
  color: white;
}
COMPILED CSS
.button {
  background: #1677c8;
  color: white;
}
32 / CSS LEARNING PATH

SCSS nesting and mixins

Organize reusable patterns

Keep nesting shallow to avoid overly complex selectors.

  • & refers to the parent selector
  • @mixin defines reusable declarations
  • @include inserts them
@mixin pill($bg) {
  background: $bg;
  border-radius: 999px;
}
.btn {
  @include pill(#1677c8);
  &:hover { opacity: .9; }
}
